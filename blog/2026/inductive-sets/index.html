Inductive Sets and Natural Numbers

Natural Numbers, Inductive Proofs and Indexing

Inductive Sets
Finite Indexing

Up until this point, we have been dodging a very important problem. We started this series with sets because they are allegedly among the most fundamental entities in mathematics. Yet we all start learning mathematics by counting. So shouldn’t numbers indisputably be the most fundamental thing?

We dug ourselves further into this hole with the axiom of foundation, which demands that every non-empty set have an element disjoint from it. That leads to a very strange observation. For the axioms to make sense, every element of a set must itself be a set, otherwise “disjoint” means nothing. And yet in the last post we happily took unions and intersections of sets of numbers. So, are numbers themselves sets? To answer that, we first need to look at something broader.

Inductive Sets

Every set we build from the axioms starts from somewhere, and the only set the axioms hand us for free is $\varnothing$. Here is a way to keep growing new sets out of old ones. For any set $n$, define its successor to be

\[S(n) := n \cup \lbrace n \rbrace,\]

the set $n$ with $n$ itself thrown in as one extra element. The axiom of pairing (applied to $n$ with itself) gives us $\lbrace n \rbrace$, and the axiom of union then gives us $n \cup \lbrace n \rbrace$, so $S(n)$ is always a set.

Definition 2.12. A set $I$ is called an inductive set if and only if $\varnothing \in I$ and $\forall n \in I : S(n) \in I$.

In plain English: an inductive set contains the empty set, and whenever it contains something, it also contains that thing’s successor.

Remark 2.6. This definition is what makes the axiom of infinity precise. Stated properly, the axiom says: there exists an inductive set. Such a set really must be infinite, since starting from $\varnothing$, the successor lets us add new elements to it ad infinitum.

So what is inside an inductive set? Let us start from $\varnothing$ and keep taking successors, giving each new set a rather suggestive name:This is the construction due to John von Neumann. There are other constructions of the naturals from sets, which give slightly different interpretations.

\[\begin{aligned} 0 &:= \varnothing, \\ 1 &:= S(0) = \varnothing \cup \lbrace 0 \rbrace = \lbrace 0 \rbrace, \\ 2 &:= S(1) = 1 \cup \lbrace 1 \rbrace = \lbrace 0, 1 \rbrace, \\ 3 &:= S(2) = 2 \cup \lbrace 2 \rbrace = \lbrace 0, 1, 2 \rbrace, \\ &\;\;\vdots \\ k + 1 &:= S(k) = k \cup \lbrace k \rbrace = \lbrace 0, 1, 2, \dots, k \rbrace. \end{aligned}\]

These are the finite ordinals, and every inductive set contains all of them. The natural numbers should be exactly these sets and nothing else. The cleanest way to say “nothing else” is to keep only what every inductive set is forced to contain.

Definition 2.13. Let $I_0$ be an inductive set. The set of natural numbers is

\[\mathbb{N} := \lbrace x \in I_0 : x \in I \text{ for every inductive set } I \rbrace.\]

The axiom of infinity guarantees that some inductive set $I_0$ exists, and the axiom of specification then makes $\mathbb{N}$ a set. Notice that we only carve $\mathbb{N}$ out of $I_0$. We never write “the set of all $x$ that are in every inductive set” without saying where the $x$ come from, because that is exactly the habit that got us into Russell’s paradox.

Theorem 2.9. The set $\mathbb{N}$ is an inductive set, and it is a subset of every inductive set. It does not depend on which inductive set $I_0$ we started from.

Proof

$\mathbb{N}$ is a subset of every inductive set. Let $I$ be any inductive set and let $x \in \mathbb{N}$. By Definition 2.13, $x$ belongs to every inductive set, in particular to $I$. So $\mathbb{N} \subseteq I$.

$\mathbb{N}$ is inductive. Every inductive set contains $\varnothing$, and $I_0$ is one of them, so $\varnothing \in I_0$ and $\varnothing \in \mathbb{N}$. Now let $n \in \mathbb{N}$. Then $n \in I$ for every inductive set $I$, and since each such $I$ is inductive, $S(n) \in I$ for every inductive set $I$. In particular $S(n) \in I_0$, so $S(n) \in \mathbb{N}$.

Independence of $I_0$. Let $I_0’$ be another inductive set and $\mathbb{N}’$ the set obtained from it. By the first part (applied to $\mathbb{N}$), $\mathbb{N} \subseteq I_0’$, and every element of $\mathbb{N}$ is in every inductive set, so $\mathbb{N} \subseteq \mathbb{N}’$. Swapping the roles of $I_0$ and $I_0’$ gives $\mathbb{N}’ \subseteq \mathbb{N}$. By antisymmetry (Theorem 2.8), $\mathbb{N} = \mathbb{N}’$. $\square$

In other words, $\mathbb{N}$ is the smallest inductive set, and its elements are precisely $0, 1, 2, 3, \dots$ from the construction above.

Remark 2.7. Before we go any further, let us take a step back and appreciate the philosophical wisdom of the distant past, in which the number zero was always associated with emptiness, void and nothingness. Modern mathematics, in all its glory, gives that idea a precise logical form: $0$ is nothing but a name, or label, for the empty set.Roughly speaking, starting from $0 = \varnothing$ also makes the construction more natural than starting from the set containing the empty set, i.e., $1$.

This also settles the puzzle about the axiom of foundation from Remark 2.1. Take $\lbrace 1, 2, 3 \rbrace$. Its element $1 = \lbrace 0 \rbrace$, and $0 \notin \lbrace 1, 2, 3 \rbrace$, so $1 \cap \lbrace 1, 2, 3 \rbrace = \varnothing$. The number $1$ is literally a set disjoint from $\lbrace 1, 2, 3 \rbrace$, exactly as foundation demands.

While we have defined the natural numbers as a set, we have also quietly used a symbol, $+$, which is not native to the language of sets. Let us formalise it.

Definition 2.14. For any $m, n \in \mathbb{N}$, the sum $m + n$ is the set obtained by applying the successor $n$ times, starting from $m$:Making "apply $S$ exactly $n$ times" fully rigorous needs a result called the recursion theorem. The equivalent recursive form, $m + 0 = m$ and $m + S(n) = S(m + n)$, appears in the exercises at the end of this chapter.

\[m + n := S^n(m), \qquad \text{where } S^0(m) := m \text{ and } S^{k+1}(m) := S\big(S^k(m)\big).\]

Remark 2.8. In essence, adding $n \in \mathbb{N}$ to $m \in \mathbb{N}$ boils down to starting at $m$ and taking the successor as many times as there are elements in $n$.Other valid constructions could have other interpretations, but at the end of the day they would still be built out of sets. In particular $n + 1 = S(n)$, which is why we were allowed to write $k + 1$ in the construction above.

Exercise 2.5. Show that for any $m, n \in \mathbb{N}$, $m + n = n + m$.

Solution

We use the principle of mathematical induction, Theorem 2.10 below, several times. Straight from Definition 2.14, for all $m, n \in \mathbb{N}$,

\[m + 0 = m \qquad \text{and} \qquad m + S(n) = S^{n+1}(m) = S\big(S^n(m)\big) = S(m + n). \tag{$\ast$}\]

Step 1: $0 + m = m$ for all $m \in \mathbb{N}$. Induction on $m$. Base case: $0 + 0 = 0$ by $(\ast)$. Inductive step: if $0 + k = k$, then $0 + S(k) = S(0 + k) = S(k)$ by $(\ast)$.

Step 2: $S(m) + n = S(m + n)$ for all $m, n \in \mathbb{N}$. Fix $m$ and use induction on $n$. Base case: $S(m) + 0 = S(m) = S(m + 0)$ by $(\ast)$. Inductive step: if $S(m) + k = S(m + k)$, then

\[S(m) + S(k) = S\big(S(m) + k\big) = S\big(S(m + k)\big) = S\big(m + S(k)\big),\]

using $(\ast)$, the hypothesis, and $(\ast)$ again.

Step 3: $m + n = n + m$. Fix $m$ and use induction on $n$. Base case: $m + 0 = m = 0 + m$, by $(\ast)$ and Step 1. Inductive step: if $m + k = k + m$, then

\[m + S(k) = S(m + k) = S(k + m) = S(k) + m,\]

using $(\ast)$, the hypothesis, and Step 2. By induction, $m + n = n + m$ for all $n$, and since $m$ was arbitrary, for all $m$ too. $\square$

Definition 2.15. The cardinality or cardinal number of a set $A$ is the number of elements in it, and is denoted by $\lvert A \rvert$.

Remark 2.9. Look closely at the construction of $\mathbb{N}$, and you will notice that these numbers play a dual role. First, they answer the question which count? (their ordinal role). For example, $3 = \lbrace 0, 1, 2 \rbrace$ is the third non-empty set in our construction. Second, they tell us how many elements are in the set (their cardinal role), since the set $3$ contains exactly $3$ elements, i.e., $\lvert 3 \rvert = 3$. Pick any natural number from our construction and you will find that the count and the size match perfectly.

Definition 2.16. For any $m, n \in \mathbb{N}$, we say that $m$ is less than $n$, written $m \lt n$, whenever $m \subset n$. Equivalently, $n$ is greater than $m$, written $n \gt m$, when $n \supset m$.

So $2 \lt 3$ because $\lbrace 0, 1 \rbrace \subset \lbrace 0, 1, 2 \rbrace$. Ordering numbers turns out to be nothing more than proper inclusion of sets.

Exercise 2.6. Show that if $a, b, c \in \mathbb{N}$ are such that $a \gt b$ and $b \gt c$, then $a \gt c$.

Solution

By Definition 2.16, we have $c \subset b$ and $b \subset a$, and we must show $c \subset a$, i.e., $c \subseteq a$ and $c \neq a$.

$c \subseteq a$. Since $c \subseteq b$ and $b \subseteq a$, transitivity (Theorem 2.8) gives $c \subseteq a$.

$c \neq a$. Since $c \subset b$, we have $c \neq b$, so by Exercise 2.1 $b \not\subseteq c$ (otherwise $c \subseteq b$ and $b \subseteq c$ would force $c = b$). So there is some $x \in b$ with $x \notin c$. Since $b \subseteq a$, $x \in a$. Thus $x \in a$ but $x \notin c$, so $a \neq c$ by the axiom of extension.

Hence $c \subset a$, i.e., $a \gt c$. $\square$

Remark 2.10. To add to Remark 2.9: if we try to stretch these finite sets to infinity, the dual role breaks down. We can talk about the size of an infinite set using infinite cardinal numbers, like $\lvert \mathbb{N} \rvert$,We will revisit the notion of infinity when we study functions. but we cannot use our finite counting numbers to reach some unique “infinity-th” position. What we can do is label the position reached by the set $\mathbb{N}$ itself as the first infinite ordinal, $\omega := \mathbb{N}$. Its successor $\omega + 1 := S(\omega) = \omega \cup \lbrace \omega \rbrace$ is a perfectly good set, and if we extend Definition 2.16 to such sets, $\omega \subset \omega + 1$, so $\omega + 1 \gt \omega$. On the other hand, adding one element to an infinite set intuitively still leaves a set of the same infinite size, so $\lvert \omega + 1 \rvert = \lvert \mathbb{N} \rvert$. This is the crux of the poorly phrased idea that “infinity is not a number but a concept”. The fact of the matter is that count and size behave very differently once the size is infinite!

Now for the reason anyone outside set theory cares about any of this.

Theorem 2.10 (Principle of Mathematical Induction). Let $P(n)$ be a predicate on $\mathbb{N}$ such that

  • (Base case) $P(0)$ is true, and
  • (Inductive step) $\forall k \in \mathbb{N} : P(k) \implies P(k + 1)$.

Then $\forall n \in \mathbb{N} : P(n)$ is true.

Proof

By the axiom of specification, $A := \lbrace x \in \mathbb{N} : P(x) \rbrace$ is a set, and $A \subseteq \mathbb{N}$. We show that $A$ is inductive.

By the base case, $P(0)$ holds, and $0 = \varnothing \in \mathbb{N}$, so $\varnothing \in A$. Now let $k \in A$. Then $k \in \mathbb{N}$ and $P(k)$ holds. Since $\mathbb{N}$ is inductive (Theorem 2.9), $S(k) = k + 1 \in \mathbb{N}$, and by the inductive step $P(k + 1)$ holds. So $S(k) \in A$, and $A$ is inductive.

By Theorem 2.9, $\mathbb{N}$ is a subset of every inductive set, so $\mathbb{N} \subseteq A$. Together with $A \subseteq \mathbb{N}$, antisymmetry (Theorem 2.8) gives $A = \mathbb{N}$. That is, $P(n)$ holds for every $n \in \mathbb{N}$. $\square$

Think of it as a line of dominoes: knock over the first one, make sure each one knocks over the next, and they all fall. The proof above is the set-theoretic reason the dominoes can’t skip any: $\mathbb{N}$ has no elements other than the ones the successor reaches from $0$.

Remark 2.11. Induction is a really powerful technique for writing proofs about any inductive set, and nothing forces us to start at $0$. It extends to the integers from any starting point onwards.We will see more general versions of this when we study functions.

Theorem 2.11. Let $m \in \mathbb{Z}$, and let $P(n)$ be a predicate on the integers $n \geq m$ such that $P(m)$ is true and $P(k) \implies P(k + 1)$ for every integer $k \geq m$. Then $P(n)$ is true for every integer $n \geq m$.

Proof

For $j \in \mathbb{N}$, define the predicate $Q(j) :\iff P(m + j)$. We check the two conditions of Theorem 2.10 for $Q$.

Base case. $Q(0) \iff P(m)$, which is true.

Inductive step. Let $j \in \mathbb{N}$ with $Q(j)$ true, i.e., $P(m + j)$ is true. Since $j \geq 0$, the integer $k := m + j$ satisfies $k \geq m$, so $P(k) \implies P(k + 1)$ applies and $P(m + j + 1)$ is true. That is exactly $Q(j + 1)$.

By Theorem 2.10, $Q(j)$ is true for every $j \in \mathbb{N}$. Now let $n \geq m$ be any integer. Then $j := n - m \geq 0$ is a natural number, and $Q(n - m) \iff P(n)$, so $P(n)$ is true. $\square$

Here is induction in action.

Example 2.17. Prove that $\forall n \in \mathbb{N} : P(n)$, where $P(n) :\iff 3 \mid (n^3 + 2n)$.

Proof

We use Theorem 2.10.

Base case. $P(0) :\iff 3 \mid 0$, which is true, since $0 = 3 \cdot 0$.

Inductive step. Let $k \in \mathbb{N}$ be such that $P(k)$ is true, i.e., $3 \mid (k^3 + 2k)$. We need to show that $3 \mid \big((k + 1)^3 + 2(k + 1)\big)$. Expanding,

\[(k + 1)^3 + 2(k + 1) = k^3 + 3k^2 + 3k + 1 + 2k + 2 = (k^3 + 2k) + 3(k^2 + k + 1).\]

The first bracket is divisible by $3$ by the hypothesis $P(k)$, and the second term is visibly a multiple of $3$. So their sum is divisible by $3$, and $P(k + 1)$ is true.

Since our choice of $k$ was arbitrary, $\forall k \in \mathbb{N} : P(k) \implies P(k + 1)$. Therefore, by induction, $\forall n \in \mathbb{N} : P(n)$ is true. $\square$

Notice where the hypothesis did its job: we rearranged $P(k + 1)$ until $P(k)$ appeared inside it. That is the whole trick, nearly every time.

Exercise 2.7. Show that $9^n - 1$ is divisible by $8$ for all natural numbers $n$.

Solution

Let $P(n) :\iff 8 \mid (9^n - 1)$. We use Theorem 2.10.

Base case. $9^0 - 1 = 0 = 8 \cdot 0$, so $P(0)$ is true.

Inductive step. Let $k \in \mathbb{N}$ with $P(k)$ true, so $9^k - 1 = 8q$ for some integer $q$. Then

\[9^{k+1} - 1 = 9 \cdot 9^k - 1 = 9(9^k - 1) + 9 - 1 = 9 \cdot 8q + 8 = 8(9q + 1),\]

so $8 \mid (9^{k+1} - 1)$ and $P(k + 1)$ is true. By induction, $8 \mid (9^n - 1)$ for every $n \in \mathbb{N}$. $\square$

A running theme from here on will be to construct newer sets of numbers out of the ones we already have, moving up from the naturals to the integers, and all the way up to the real and complex numbers. That needs more sophisticated machinery, so it will be rather slow going, and we will also have to rebuild arithmetic on each new set as we go. In the meantime, we will keep using these numbers in soft examples, wherever the intuition from middle school can be readily applied.

Finite Indexing

It will be convenient to introduce the notion of indexing, as it lets us write various operations far more compactly.

Definition 2.17 (Arbitrary Unions and Intersections). The union of all $x \in S$ is written

\[\bigcup_{x \in S} x.\]

Similarly, for non-empty $S$,The intersection over an empty $S$ would have to contain everything, and we have already seen that there is no set of everything. the intersection of all $x \in S$ is written

\[\bigcap_{x \in S} x.\]

The union is a set by the axiom of union. The intersection is a set by the axiom of specification: pick any $y \in S$ and keep those elements of $y$ that lie in every $x \in S$.

Example 2.18. Let $S = \lbrace \lbrace 1, 2 \rbrace, \lbrace 4, 3, 2 \rbrace, \lbrace 5, 2 \rbrace \rbrace$. Then

\[\bigcup_{x \in S} x = \lbrace 1, 2 \rbrace \cup \lbrace 4, 3, 2 \rbrace \cup \lbrace 5, 2 \rbrace = \lbrace 1, 2, 3, 4, 5 \rbrace \quad \text{and} \quad \bigcap_{x \in S} x = \lbrace 1, 2 \rbrace \cap \lbrace 4, 3, 2 \rbrace \cap \lbrace 5, 2 \rbrace = \lbrace 2 \rbrace.\]

When $S$ is a finite set, we can express the same things in terms of an index set.

Definition 2.18 (Index Set). For a finite set $S$ and some $n \in \mathbb{Z}$, the set

\[I_n := \lbrace k \in \mathbb{Z} : n \leq k \leq n + \lvert S \rvert - 1 \rbrace\]

is called a finite index set for $S$. If $S$ is a set of sets whose elements are labelled $x_k$ with $k \in I_n$, then

\[\bigcup_{k \in I_n} x_k = \bigcup_{k = n}^{m} x_k = x_n \cup x_{n+1} \cup x_{n+2} \cup \dots \cup x_m, \qquad \text{where } m = n + \lvert S \rvert - 1.\]

Remark 2.12. Intuitively, the index set $I_n$ just lets us put labels on the sets in $S$ and operate on them. How we do the labelling does not matter, since for finite unions and intersections the order of operations is itself irrelevant (thanks to commutativity and associativity, Theorem 2.5). It is quite common to choose $I_n$ with $n = 0$ or $n = 1$.

Finite indexing is particularly useful for writing sums as well. There we use the symbol $\Sigma$ instead of $\bigcup$ to denote addition, and the objects being combined are numbers instead of sets.

Definition 2.19 (Summation). For a finite set $S \subset \mathbb{R}$, the sum of all $x \in S$ is written

\[\sum_{x \in S} x.\]

Example 2.19. Let $S = \lbrace -1.7, \pi, 5, -3 \rbrace$. Then

\[\sum_{x \in S} x = (-1.7) + \pi + 5 + (-3) = \pi + 0.3.\]

Example 2.20. With the elements of $S$ labelled $x_k$ for $k \in I_n$,

\[\sum_{k \in I_n} x_k = \sum_{k = n}^{m} x_k = x_n + x_{n+1} + x_{n+2} + \dots + x_m, \qquad \text{where } m = n + \lvert S \rvert - 1.\]

Remark 2.13. Summation over an index set can be extended to infinite sets under some conditions as well, but we will save that discussion for when we are able to state those conditions.

When $S = I_n$ for some $n$, we tend to choose that very index set for convenience, and we can then replace the summand $x_k$ by $k$ itself, since every $x_k \in S$ is identical to some $k \in I_n$.

Example 2.21. The sum of the first $n$ positive integers is

\[\sum_{k \in I_1} k = \sum_{k = 1}^{n} k = 1 + 2 + \dots + n.\]

Exercise 2.8. Express the sum of the squares of the first $5$ naturals as a summation.

Solution

Remember our convention that $0 \in \mathbb{N}$. The first $5$ naturals are $0, 1, 2, 3, 4$, which form the index set $I_0 = \lbrace 0, 1, 2, 3, 4 \rbrace$. So the sum is

\[\sum_{k \in I_0} k^2 = \sum_{k = 0}^{4} k^2 = 0 + 1 + 4 + 9 + 16 = 30.\]

If you instead wrote $\sum_{k=1}^{5} k^2 = 55$, you summed the squares of the first $5$ positive integers, i.e., the first $5$ elements of $\mathbb{N}^{\ast}$. That is a perfectly good sum, just not the one asked for. Conventions matter!

Remark 2.14. An alternative notation for $I_n$ is $[n ; N]$, where $N = n + \lvert S \rvert - 1$ is the last index. In particular, writing $N = \lvert S \rvert$, we denote $I_1 = [1 ; N]$ by $[N]$ and $I_0 = [0 ; N - 1]$ by $[N_{\ast}]$.

So we can now count, add, compare and sum, all built out of nothing but the empty set. But mathematics is not just a line of numbers. To talk about the plane, coordinates and shapes, we need a way to pair things up, and nothing we have built so far does that. Next time, we fix that.
