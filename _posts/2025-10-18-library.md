Teaching ourselves mathematics is a strangely lonely business. Nobody tells us which book to open next, and the internet is not much help either, since half of it recommends the same three titles to everyone and the other half recommends whatever it happened to suffer through in college. This post is my attempt at something better. It is a shelf of books, lecture notes and courses that we can work through, more or less in order, to get from school mathematics to the mathematics that modern theoretical physics is actually written in.

The shelf is split into **phases**, and each phase into subjects. The books within a subject are companions rather than a checklist, so pick one as the main text and keep another nearby for the days when the first one stops making sense (there will be such days). The phases are a rough guide to prerequisites and not a syllabus. Reading Phase 2 algebra alongside Phase 3 analysis is perfectly fine, and frankly it is how most of us end up doing it anyway.

Wherever something is legally free online, I have linked it. Every entry also has a spot for a proper review, by which I mean one written by somebody who has actually read the book and not a row of stars on a shopping site. Those links will trickle in over time. And yes, I know, I know, the list is long. _Sigh_. So is mathematics.

## Phase 0 (Pre Uni Bridge)

Most of us were trained at school to compute. See the question, recall the method, write the answer and move on to the next one before the bell rings. University mathematics wants something else entirely, namely **proofs**, and the jump can feel brutal when nobody warns us about it. Consider this phase the warning. It assumes nothing beyond school algebra and calculus, so strong high school students and anyone returning to mathematics after a long break should start here. We learn how to read and write a proof, meet discrete mathematics properly, take a second and far more honest look at precalculus and calculus, and keep a serious physics text open so that the mathematics always has something to talk about.

## Phase 1 (Basics)

This is roughly the first year of a mathematics degree, minus the courses that seem to exist mainly to fill a timetable. Sets, rigorous real analysis, linear algebra done properly, probability and a little programming make up the foundation that everything else rests on. If Phase 0 taught us what a proof is, Phase 1 is where we write a few hundred of them.

## Phase 2 (Intermediate)

Once the foundations are in, the subjects start talking to each other. Calculus grows up into analysis on manifolds, algebra turns abstract, topology shows up in its own right, differential equations become dynamical systems and probability becomes statistical inference. Think of this as the second and third year of a good undergraduate programme, the kind most of us were never actually offered.

## Phase 3 (Advanced)

Welcome to graduate mathematics, which also happens to be where the physics starts showing through. Measure theory gives probability and quantum mechanics their footing, complex analysis and representation theory become everyday tools, partial differential equations move to centre stage, and differential geometry hands us the language that modern physics is written in. Each book here is a matter of months rather than weeks, so let us be kind to ourselves.

## Phase 4 (Specialised) · Pure Mathematics

By now there is a choice to make, and most of us will happily refuse to make it. The pure mathematics shelf covers algebraic geometry, algebraic topology, category theory and number theory. The theoretical physics shelf runs from classical particles and fields through quantum systems and quantum field theory to statistical physics. Quite a few books here are research-level references, so treat them as places to keep coming back to rather than books to finish.

These are the parts of pure mathematics that the rest of mathematics keeps quietly borrowing from.

(function () {
  document.documentElement.classList.add("lib-js");
  var panels = Array.prototype.slice.call(document.querySelectorAll(".lib-phase"));
  var tabs = Array.prototype.slice.call(document.querySelectorAll(".lib-tabs a"));
  var bar = document.querySelector(".lib-tabs");
  if (!panels.length) return;

  function update(g) {
    var t = g.querySelector(".lib-track");
    var max = t.scrollWidth - t.clientWidth - 2;
    g.querySelector(".lib-prev").disabled = t.scrollLeft <= 2;
    g.querySelector(".lib-next").disabled = t.scrollLeft >= max;
    var cards = t.querySelectorAll(".lib-card");
    var w = cards.length ? cards[0].getBoundingClientRect().width + 16 : 1;
    var i = Math.min(cards.length, Math.round(t.scrollLeft / w) + 1);
    var c = g.querySelector(".lib-count");
    if (c) c.textContent = cards.length > 1 ? i + " / " + cards.length : "";
    g.querySelector(".lib-controls").style.visibility = cards.length > 1 ? "visible" : "hidden";
  }
  function show(id, scroll) {
    if (!document.getElementById(id)) id = panels[0].id;
    panels.forEach(function (p) { p.classList.toggle("active", p.id === id); });
    tabs.forEach(function (a) { a.classList.toggle("active", a.getAttribute("href") === "#" + id); });
    document.querySelectorAll(".lib-phase.active .lib-gallery").forEach(update);
    if (scroll && bar) bar.scrollIntoView({ block: "start" });
  }
  function panelFor(hash) {
    if (!hash || hash.length < 2) return null;
    var el = document.getElementById(decodeURIComponent(hash.slice(1)));
    var p = el && el.closest(".lib-phase");
    return p ? p.id : null;
  }
  tabs.forEach(function (a) {
    a.addEventListener("click", function (e) {
      e.preventDefault();
      var id = a.getAttribute("href").slice(1);
      history.replaceState(null, "", "#" + id);
      show(id, true);
    });
  });
  window.addEventListener("hashchange", function () {
    var id = panelFor(location.hash);
    if (id) show(id, true);
  });
  document.querySelectorAll(".lib-gallery").forEach(function (g) {
    var t = g.querySelector(".lib-track");
    function step(dir) {
      var c = t.querySelector(".lib-card");
      var w = c ? c.getBoundingClientRect().width + 16 : 300;
      t.scrollBy({ left: dir * w, behavior: "smooth" });
    }
    g.querySelector(".lib-prev").addEventListener("click", function () { step(-1); });
    g.querySelector(".lib-next").addEventListener("click", function () { step(1); });
    t.addEventListener("scroll", function () { update(g); }, { passive: true });
  });
  window.addEventListener("resize", function () {
    document.querySelectorAll(".lib-phase.active .lib-gallery").forEach(update);
  });
  show(panelFor(location.hash) || panels[0].id, false);
})();
</script>
